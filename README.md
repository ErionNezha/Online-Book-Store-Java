# Online Book Store (Java/JSP)

Dyqan librash online në Java (JSP/Servlets) — katalog librash, shportë blerjesh, menaxhim klientësh dhe porosi.

`Java` `JSP` `MySQL`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Online-Book-Store-Java/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

Importo projektin në Eclipse/NetBeans me Tomcat; konfiguron MySQL sipas `Instructions to run.doc`.
